1.2 — Solving by Factoring (AC method)
🧠 Feynman Mode

Factoring = reverse of multiplying. Hinahanap mo ang 2 binomials na nag-multiply para maging quadratic.

🔥 Analogy: Meron kang 12. What 2 numbers mo i-multiply para makakuha ng 12? 3×4, 6×2, 12×1. Same concept — but with x.

Example: Solve x² - 5x + 6 = 0

  1. Find 2 numbers na mag-multiply to c (6) and add to b (-5). → -2 and -3 (since -2 × -3 = 6, -2 + -3 = -5).
  2. Rewrite as product: (x - 2)(x - 3) = 0
  3. Zero Product Property: kung AB=0, then A=0 OR B=0. So x - 2 = 0 OR x - 3 = 0.
  4. Solve each: x = 2, x = 3. Tapos. These are the roots.

1.3 — Solving by Extracting Square Roots
🧠 Feynman Mode

Gamit ito kapag walang "bx" term. Form: x² = k.

Example: Solve x² = 49

  1. Take square root both sides: x = ±√49
  2. √49 = 7 (remember ang ±! +7 at -7 are both solutions, kasi (-7)² = 49 din)

99% ng errors dito: kinakalimutan ang ±. Isa lang sinasagot. Then -5 points ka. 💀

1.4 — The Quadratic Formula (The God-Tier Solver)
🧠 Feynman Mode

Kung di mo ma-factor, gamitin mo ito. ALWAYS WORKS.

x = ( -b ± √(b² - 4ac) ) / ( 2a )
🔥 Memory hack: There's a song! "x is equal to negative b, plus or minus the square root, of b-squared minus four a c, all over two a." — sing it to the tune of "Pop Goes the Weasel." Legit.

Example: Solve 2x² + 3x - 5 = 0 (a=2, b=3, c=-5)

  1. Compute discriminant: b² - 4ac = 9 - 4(2)(-5) = 9 + 40 = 49
  2. √49 = 7
  3. x = (-3 ± 7) / (2·2) = (-3 ± 7) / 4
  4. x₁ = (-3 + 7)/4 = 4/4 = 1
  5. x₂ = (-3 - 7)/4 = -10/4 = -5/2
  6. Answer: x = 1 or x = -5/2

1.7 — Completing the Square
🧠 Feynman Mode

Completing the square = forcing the equation into a "perfect square" form so you can sqrt it.

Formula pattern:

(x + h)² = x² + 2hx + h² ← memorize this pattern

Example: Solve x² + 6x - 7 = 0

  1. Move constant: x² + 6x = 7
  2. Take half of b (6/2 = 3), square it (3² = 9), add to both sides:
    x² + 6x + 9 = 7 + 9
  3. Left side is now perfect square: (x + 3)² = 16
  4. Take √: x + 3 = ±4
  5. Solve: x = -3 + 4 = 1 or x = -3 - 4 = -7
🔥 Analogy: Parang Legos. Binibigay ka ng kulang na set — dapat alam mo kung anong piece ang idadag para maging complete square (perfect cube sa metaphors natin).

1.8 — Quadratic Inequalities
🧠 Feynman Mode

Instead of solving ax² + bx + c = 0, we solve ax² + bx + c < 0 or > 0. Answer = a range of x, not single values.

Steps to solve:

  1. Solve the equation as if = 0. Get the roots (critical points).
  2. Mark the roots on a number line.
  3. Test a value sa bawat region (left, between, right).
  4. Kung gumagana sa inequality, that region is part of the solution.

Example: Solve x² - 5x + 6 < 0

  1. Roots: x = 2, x = 3 (via factoring).
  2. Regions: (-∞, 2), (2, 3), (3, ∞)
  3. Test x = 0: 0 - 0 + 6 = 6 (not < 0) ❌
  4. Test x = 2.5: 6.25 - 12.5 + 6 = -0.25 (< 0) ✓
  5. Test x = 4: 16 - 20 + 6 = 2 (not < 0) ❌
  6. ✅ Answer: 2 < x < 3
Parabola opens UP? Kung "< 0," middle region ang sagot (between roots). Kung "> 0," outer regions. Chika lang.
1.9 — Quadratic Word Problems
🧠 Feynman Mode

Word problems look intimidating pero same concept lang. Translate words → equation.

Translation cheat sheet:

  • "Product ng dalawang numero" → xy
  • "Sum" → +, "Difference" → -
  • "Area" = length × width
  • "2 consecutive integers" → x, x+1
  • "2 consecutive even integers" → x, x+2

Example: Ang kuwadrado ng isang numero ay 6 na higit kaysa 5 beses ng numero. Hanapin ang numero.

  1. Let x = ang numero. Equation: x² = 5x + 6
  2. Rearrange: x² - 5x - 6 = 0
  3. Factor: (x - 6)(x + 1) = 0
  4. Roots: x = 6 or x = -1
  5. Check both: 6² = 36 = 5(6) + 6 = 36 ✓ | (-1)² = 1 = 5(-1) + 6 = 1 ✓
  6. Answer: 6 o -1

Example 2 (Area): Ang haba ay 3m na mas mahaba kaysa lapad. Area = 40 m². Find dimensions.

  1. Let w = lapad, haba = w + 3
  2. w(w+3) = 40 → w² + 3w - 40 = 0
  3. Factor: (w + 8)(w - 5) = 0
  4. w = -8 (reject, negative) or w = 5
  5. Answer: Lapad = 5m, Haba = 8m
Quarter 2: Variations + Radicals Q2
2.1 — Direct Variation (y = kx)
🧠 Feynman Mode

Direct variation: "As x goes up, y goes up" at the same ratio.

🔥 Analogy: Kumakain ka ng chicken joy. 1 piece = ₱90. 2 pieces = ₱180. 5 pieces = ₱450. The cost varies directly as the number of pieces. Ratio ng cost:piece is constant (90).
y = kx ←→ k = y/x (k is the "constant of variation")

Example: y varies directly as x. If y = 15 when x = 3, find y when x = 7.

  1. Find k: k = y/x = 15/3 = 5
  2. Plug in x = 7: y = 5(7) = 35

2.2 — Inverse Variation (y = k/x)
🧠 Feynman Mode

Inverse variation: "As x goes up, y goes DOWN" — but k (product) stays the same.

🔥 Analogy: Mga workers sa project. 1 worker = 12 days. 2 workers = 6 days. 3 workers = 4 days. More workers = less time. Product is always 12 worker-days. That's inverse variation.
y = k/x ←→ k = xy

Example: y inversely varies as x. y = 10 when x = 4. Find y when x = 8.

  1. k = xy = 4·10 = 40
  2. y = k/x = 40/8 = 5
2.3 — Joint & Combined Variation
🧠 Feynman Mode

Joint: y = kxz (varies directly as 2+ variables). Combined: mix of direct and inverse.

Joint: y = kxz Combined: y = kx/z

Example (Joint): Area ng rectangle varies jointly as length and width. A = 24 when L=4, W=3. Find A when L=6, W=5.

  1. k = A/(LW) = 24/(4·3) = 2
  2. A = k·L·W = 2(6)(5) = 60

3.5 — Proportion Theorems in Triangles
🧠 Feynman Mode

Key idea: a line parallel to one side of a triangle divides the other two sides proportionally.

4.4 — Trigonometry Word Problems (Real-Life)
🧠 Feynman Mode

Trig is used for EVERYTHING: surveying, navigation, architecture, even video game physics.

Problem 1 (Ladder): May ladder na 10m ang haba, nakasandal sa dingding. Angle na ginagawa sa ground = 65°. Gaano kataas ang naabot nito?

  3. sin(65°) ≈ 0.906
  4. opp = 10 · 0.906 ≈ 9.06 m

Problem 2 (Airplane): From a 500m high airplane, angle of depression sa airport = 20°. How far horizontally is the airport?

  1. Angle of depression = angle of elevation from airport
  2. opp = 500 (height), adj = horizontal distance = ?
  3. tan(20°) = 500/adj → adj = 500/tan(20°)
  4. tan(20°) ≈ 0.364
  5. adj = 500/0.364 ≈ 1373 m

Problem 3 (Shadow): A 6-meter tree's shadow is 8m long. What's the sun's angle of elevation?

  1. tan(θ) = opp/adj = 6/8 = 0.75
  2. θ = arctan(0.75) ≈ 36.87°

Balancing equations (step-by-step):

  1. List atoms on both sides. Count each element.
  2. Balance one element at a time. Start with the most complex.
  3. Adjust coefficients (numbers in front). NEVER change subscripts.
  4. Save H and O for last. Double-check.

Example: Balance Fe + O₂ → Fe₂O₃

  1. Left: 1 Fe, 2 O. Right: 2 Fe, 3 O.
  2. Balance Fe: put 2 in front of Fe → 2Fe + O₂ → Fe₂O₃
  3. Balance O: LCM of 2 and 3 = 6. Use 3O₂ (6 O's) and 2Fe₂O₃ (6 O's).
  4. Now Fe: need 4 on left: 4Fe + 3O₂ → 2Fe₂O₃
  5. ✅ Balanced: 4Fe + 3O₂ → 2Fe₂O₃

  • Parallel — multiple paths. Remove 1 bulb, others work. Total R smaller than smallest individual.

Example: A device uses 6V battery, has 2 ohm resistance. What's the current?

  1. V = IR → I = V/R
  2. I = 6/2 = 3 amperes
